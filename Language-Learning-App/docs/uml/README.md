# PlantUML diagrams

The five `.puml` files describe Adapter, Decorator, Observer, the project classes, and answer submission.

Install PlantUML and Graphviz, then run from the project directory:

```powershell
plantuml -tpng docs/uml/*.puml
```

Alternatively, open each `.puml` file in an IDE with a PlantUML plugin and choose **Export Diagram → PNG**. The PNG files will appear next to their sources.
